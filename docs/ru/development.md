# Разработка

Эта страница для тех, кто работает над самим LumiCells: подготовка, скрипты, тесты и страницы для
разработки.

## Подготовка

В клоне репозитория:

```bash
npm ci
npm run dev   # http://localhost:5173/
```

## Скрипты

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Стенд и примеры |
| `npm run build` | Проверка типов и сборка стенда в `dist-demo` |
| `npm run build:lib` | Сборка пакета в `dist/lib` и типов в `dist/types` |
| `npm run check:types` | Проверка типов собранного пакета глазами потребителя |
| `npm test` | Юнит-тесты (Vitest) |
| `npm run typecheck` | Проверка типов |
| `npm run lint` | Biome |
| `npm run test:e2e` | Сквозные тесты в браузере (Playwright: Chromium, Firefox, WebKit) |
| `npm run size` | Размеры бандла потребителя против бюджета (после `npm run build:lib`) |

Сборка пакета для своего приложения описана в разделе [Установка](installation.md), бюджеты
размера в разделе [Производительность](performance.md#размер-бандла).

## Сквозные тесты

Перед первым e2e-запуском выполните `npx playwright install chromium firefox webkit`. Каждый
сценарий идёт во всех трёх браузерах; `npm run test:e2e -- --project=firefox` запускает один.

Переключатели GPU, порта и сервера описаны в
[`tests/e2e/support/env.ts`](../../tests/e2e/support/env.ts): CI рисует программно (по задаче на
браузер: SwiftShader в Chromium, llvmpipe из Mesa в Firefox и WebKit), локальный запуск идёт через
аппаратный GPU.

Сквозные тесты проверяют жёсткие инварианты в каждом браузере (ноль потерь контекста, бюджет
контекстов, все видимые карточки живые, нет утечек за 20 циклов монтирования и удаления,
восстановление после потери контекста, страницы попиксельного паритета) и пишут тайминги в
`test-results/e2e-perf.json`. Кучу JS после этих циклов проверяет только Chromium (нужен CDP).
Сообщения консоли, которые браузер пишет о своём собственном поведении, перечислены с причиной в
[`tests/e2e/support/known-issues.ts`](../../tests/e2e/support/known-issues.ts); пределы таймингов
для браузеров кроме Chromium стоят в сценариях рядом со своими замерами.

Какие браузеры где проверяются и чем они отличаются, описано в разделе
[Поддержка браузеров](browser-support.md).

## Страницы для разработки

| Адрес | Что там |
| --- | --- |
| `/` | Стенд с панелью настроек и демо-сценой ([Стенд](playground.md)) |
| `/examples/web-component.html` | Web Component в чистом HTML, декларативная привязка через `data-lc-*` |
| `/examples/core-basic.html` | Ядро без фреймворков, вылет пикселей за границы карточки |
| `/examples/engine-harness.html` | Отладка движка: проходы по отдельности, замер времени кадра |
| `/examples/tune.html` | Детерминированное время для сравнения скриншотов |
| `/examples/scene-preview.html` | Демо-сцена отдельно, поверх статичной замены фона |
| `/examples/ui-kit.html` | UI-кит стенда |

Первые три опубликованы и на GitHub Pages: стенд на
[supsad.github.io/lumicells](https://supsad.github.io/lumicells/) и два примера рядом с ним.
