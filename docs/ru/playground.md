# Стенд

Стенд для настройки собран на Vite: поверх фона на нём работает демо-сцена с плавающими баблами.
**[supsad.github.io/lumicells](https://supsad.github.io/lumicells/)** открывает его вживую.

## Что можно делать

- переключать 9 пресетов и крутить любой параметр с плавными переходами;
- менять размер сцены (весь экран, карточка 360×360, баннер 1200×320, телефон 390×844, свой
  размер);
- включать демо-сцену, интерактив и отладочные слои (поле, ореол, bloom, дымка, ячейки);
- ставить анимацию на паузу и имитировать потерю контекста;
- смотреть FPS, время кадра на CPU и GPU, уровень качества, число пикселей и ячеек;
- отменять и повторять изменения (история), конфиг сохраняется автоматически;
- экспортировать вид как JSON, TypeScript, React или HTML, импортировать конфиг обратно или
  скопировать ссылку с конфигом в адресе (см.
  [Экспорт и импорт на стенде](config.md#экспорт-и-импорт-на-стенде)).

## Панель настроек

Панель справа строится из схемы параметров автоматически (см. [Как устроено](architecture.md)).
Каждая ручка показывает подсказку и путь в конфиге, двойной щелчок по названию возвращает
значение пресета.

Горячие клавиши: `H` панель, `P` пауза, `D` отладочный слой, `Ctrl+Z` / `Ctrl+Shift+Z` история.

Интерфейс на английском и русском: переключатель EN/RU или `?lang=ru` в адресе.

## Локальный запуск

В клоне репозитория команды `npm ci` и затем `npm run dev` запускают стенд на
`http://localhost:5173/`. Другие страницы для разработки перечислены в разделе
[Разработка](development.md#страницы-для-разработки).
