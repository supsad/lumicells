# Конфигурационный файл

Вид фона задаётся JSON-конфигом. [Стенд](playground.md) экспортирует его как
`lumicells.config.json`:

```json
{
  "$schema": "./lumicells.schema.json",
  "version": 1,
  "extends": "reference",
  "grid": { "count": 36, "gap": 0.25 },
  "color": { "palette": ["#f21239", "#6a3cc8", "#0476ff", "#19e6d0"] }
}
```

- Файл можно сохранить полностью или только разницей относительно пресета (`extends`). Полный
  файл не поменяется, если позже изменятся дефолты библиотеки. Пресеты перечислены в разделе
  [Пресеты и режимы анимации](presets-and-modes.md#пресеты).
- `lumicells.schema.json` собирается вместе с пакетом (`lumicells/schema.json`) и скачивается со
  стенда, редактор по нему подсказывает поля и диапазоны.
- `normalizeConfig(raw)` никогда не бросает исключение: чинит типы, обрезает диапазоны, выкидывает
  неизвестные ключи и возвращает список замечаний с путями. `validateConfig(raw)` строже и
  подходит для проверки в CI.

## Как использовать файл

- **React**: импортируйте JSON и передайте его в проп `config` (см. пример в разделе
  [React](react.md#пример)).
- **Web Component**: укажите файл в атрибуте `src` или задайте свойство `config` (см.
  [Web Component](web-component.md)).
- **TypeScript без фреймворков**: передайте его в опцию `config` или примените позже через
  `setConfig()` или `replaceConfig()` (см. [TypeScript без фреймворков](vanilla.md#изменение-конфига)).

## Экспорт и импорт на стенде

*Экспорт* отдаёт JSON (полностью или разницей), готовые сниппеты для TypeScript, React и HTML и
JSON Schema. *Импорт* принимает файл или вставленный текст и сообщает, что исправил. *Ссылка*
копирует адрес с конфигом внутри.
