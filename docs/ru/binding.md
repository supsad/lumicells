# Привязка к окружению

Фон знает о том, что происходит вокруг, через четыре механизма: влияния, волны и подъёмы,
модуляции и координаты, которые связывают их со страницей.

Примеры написаны для [API без фреймворков](vanilla.md), где `cells` хранит экземпляр
`LumiCells`. В React для этого есть хуки `useInfluence`, `usePulse` и `useModulator`
([React](react.md#хуки)). В HTML влияния, волны и подъёмы можно объявить на дочерних элементах
атрибутами `data-lc-*` ([Web Component](web-component.md#декларативная-привязка-дочерних-элементов)).

## Влияния

**Влияния** (`bindElement`, `addInfluence`). Прямоугольник со скруглением или круг, который
добавляет свет (`light`), затемняет (`shadow`, например под заголовком для читаемости), поднимает
пиксели (`lift`), сеет «жизнь» (`seed`) или отталкивает узор (`repel`). Влияний может быть сколько
угодно: в шейдер попадают 64 самых важных по приоритету и площади, остальные ждут, смена идёт
плавно.

```ts
const light = cells.bindElement(el, { type: 'light', color: '#0481f5', strength: 0.8 });
light.update({ strength: 1.3 }); // при наведении
light.dispose();

// Тёмная область под заголовком, чтобы текст читался.
cells.bindElement(title, { type: 'shadow', padding: 24 });
```

### Режимы слежения

Опция `track` задаёт, как следить за привязанным элементом:

- `auto` читает положение, только пока элемент может двигаться (resize, scroll, CSS-переходы,
  Web Animations);
- `frame` читает каждый кадр;
- `manual` не трогает DOM, координаты передаёт ваш код через `update({ x, y, w, h })`.

Элементы, которые двигает JS, лучше анимировать в `onBeforeFrame` из `lumicells`, тогда подсветка
не отстаёт даже на кадр.

## Волны и подъёмы

**Разовые события** (`pulse`, `lift`). Волна из точки и подъём пикселей в точке.

```ts
cells.pulse({ x: 0.5, y: 0.5, space: 'norm', color: '#19e6d0', strength: 1 });
cells.lift({ x: 12, y: 8, space: 'cells', count: 6, radius: 2 });
```

Как выглядят всплывающие пиксели, описано в разделе
[Пресеты и режимы анимации](presets-and-modes.md#всплывающие-пиксели).

## Модуляции

**Модуляции** (`modulate`). Любой числовой параметр можно вести от внешнего источника: числа,
функции или объекта с `get()`. Режимы: `add`, `mul`, `override`, `max`, по желанию со
сглаживанием. Модуляции живут только в рантайме и не попадают в сохранённый конфиг, поэтому не
спорят со [стендом](playground.md).

```ts
// Сфера растёт, пока на странице что-то происходит.
const m = cells.modulate('modes.sphere.radius', () => activity * 0.1, {
  blend: 'add',
  smoothingMs: 150,
});

// Внешняя энергия, например уровень звука.
cells.setEnergy(1.4);
```

## Координаты

**Координаты** (`space`) бывают `host` (CSS px от угла контейнера), `client` (px окна, как у
`PointerEvent`), `norm` (0..1 контейнера) и `cells` (клетки сетки).
