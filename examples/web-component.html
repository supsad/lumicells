<pixel-life> без фреймворка

Обычный HTML: тег, атрибуты preset, interactive, src и декларативная привязка элементов через data-pl-*.

1. Сцена из HTML-пузырей

Каждый пузырь с data-pl-influence подсвечивает сетку под собой, data-pl-pulse="click" запускает круг по клику, data-pl-lift="hover" поднимает пиксели при наведении. Цвет света (data-pl-color) синих пузырей светлее их заливки, чтобы они не сливались с собственной подсветкой.
